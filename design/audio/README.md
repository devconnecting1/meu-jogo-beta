# Last Town — our own sound effects

Generated by `npm run audio:sfx` (`tools/gen-sfx.mjs`) — do not edit by hand; the rules are DESIGN_RULES **SND**.
Listen before uploading: open `docs/audio/preview.html` from the repository (it plays the banks below).

## How it gets into the game

1. `npm run audio:sfx` renders every take and packs them into the five banks of `banks/` (one WAV each).
2. On the PC, with the `.env`: `npm run cloud -- upload-audio` uploads the banks that are new or changed
   (Open Cloud Assets API, `assetType: Audio`, `audio/wav`), writes their ids and hashes to `assets.json` and
   regenerates `src/shared/data/audioAssets.ts`. `-- upload-audio --dry-run` lists them without reading any key.
3. `npm run build`, commit `design/audio/assets.json` + `src/shared/data/audioAssets.ts`.

Until a bank has an id — or if the client cannot load it — every event on it keeps the library take it had
before (SND-01, like ART-01 for the town's art).

## What stays on the library, and why

Organic sound is what a synthesiser does worst and a recording does best, so these keep their official
library takes (`design/audio-credits.md`): the horde's voices (groans, snarls, the group shout, the death),
the boss roar, the bite, the survivor's hurt and death, the doors, eating, the bandage, the kit's zipper, the
pills, the flamethrower's jet and ignition, the motorcycle's engine and horn, the bicycle's bell, the
explosion, breaking glass, the night music and the day and dawn ambiences.
